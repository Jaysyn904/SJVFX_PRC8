# Sunjammer's VFX Browser [PRC8]

Repository for the development of the PRC8 version of Sunjammer's VFX Browser..

[Discussion Thread on Discord](https://discord.gg/ca2ru3KxYd)

## Requirements
1.) [Nasher](https://github.com/squattingmonk/nasher), installed in your system path.

2.) [Original module resources](https://neverwintervault.org/project/nwn1/other/tool/sunjammers-vfx-browser)

3.) [PRC8](https://gitea.raptio.us/Jaysyn/PRC8/releases)

## Instructions

	Run the pack_module.cmd file to generate the module.
